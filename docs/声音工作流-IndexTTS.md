# 声音工作流：IndexTTS 2.5 本地音色克隆（单张 RTX 3090）

## 为什么换它

当前定版声线 2 是云端 TTS 加变调：能用，但每期都要走云端、情感只能靠语速硬撑。IndexTTS 2.5（哔哩哔哩 IndexTeam 开源）是零样本音色克隆：一段参考音频定音色，情感与音色解耦、可独立控制。换成本地克隆后，小缪的声音成为固定资产：离线、免费、每期一致，还能按分段给情感。

## 硬件账（单张 3090 / 24GB）

- 权重总量约 5.9GB（GPT 主模型 3.48GB + s2mel 1.2GB + Qwen 情感模型 1.19GB），磁盘另留约 10GB。
- 显存无官方指标；社区实测 FP16 推理约 4–6GB，12GB 已宽裕。3090 的 24GB 可以全量常驻，还能剩约 18GB 给录屏编码等其他活——这个工作流一张卡就够，不占论文的卡池规划。
- 速度（社区数据，非官方）：预热后约每 10 字 1 秒量级；一条 60 秒视频约 250–300 字台词，合成在一分钟内。
- IndexTTS-2.5 支持中/英/日/西/阿五语，推理可用 BF16 降显存；2.0 用 FP16。

## 一次性定版（只做一次）

1. **备参考音频**：5–15 秒、干净、单人、无背景音。来源用我们自己的合成声线，无真人声音权益问题。
   - 主选：现定版样本 `voice/voice-final.mp3`（已带 +18% 娃娃音高）作音色提示，克隆结果直接继承娃娃音高。
   - 备选：未变调的 `voice-final-raw.mp3`，输出端再统一变调。对照试听后二选一，防变调伪影被克隆放大。
2. **存为命名音色预设**（preset），命名 `xiaomiu-v1`；参考音频与参数（版本、精度、采样开关）一并记录在本文件末尾的定版表。
3. **验收**：用固定验收句（开号台词 + 一句多音字句 + 一句英文工具名）生成，与声线 2 样本 A/B；过关才切换生产线。`use_random` 保持关闭——开随机采样会降低克隆还原度。

## 每期生产（情感预设）

情感三路可控：情感参考音频、8 维情感向量、文本描述情感（Qwen 软指令）。生产线固定用 **8 维向量预设**，顺序为 [高兴， 愤怒， 悲伤， 害怕， 厌恶， 忧郁， 惊讶， 平静]，`emo_alpha` 默认 0.6（官方建议文本情感约 0.6 更自然；向量预设可从 0.65 起调）：

| 段落 | 娃娃姿势 | 情感向量预设 |
|---|---|---|
| 钩子 | 欢呼 | 高兴 0.7 / 惊讶 0.5 |
| 任务与实测讲解 | 思考 | 平静 0.8 / 高兴 0.2 |
| 得分宣布 | 得意打分 | 高兴 0.9 / 惊讶 0.2 |
| 翻车吐槽 | 翻车捂脸 | 忧郁 0.4 / 厌恶 0.3 / 惊讶 0.3 |
| 结尾招呼 | 主视觉 | 高兴 0.6 / 平静 0.4 |

脚本分段时每段标一个预设名，合成脚本按预设查表，不逐段手调。

## 对接现有流水线

- 在 3090 机器上常驻 IndexTTS 2.5（WebUI 或 Python `IndexTTS2.infer` 批量脚本均可）。
- 输入：分段脚本 JSON（每段 text + emotion_preset）；输出：`voice/seg1.wav … segN.wav`，与现有合成脚本的输入接口完全一致，`assemble` 之后的环节零改动。
- 两种运行方式：① Joseph 在本机跑批量脚本，我给脚本包；② 机器接入 Tailscale 后我远程驱动。先用方式 ① 跑通样片 002。
