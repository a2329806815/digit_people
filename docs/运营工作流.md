# 运营工作流

## 五层复刻结构（对标鲸鱼娘角色包的公开解剖）

1. **人格层**：性格、口头禅、梗库、边界，写成可加载的配置。小缪的人格即 Muse 本人的工作方式角色化：认真、好奇，翻车先嘴硬再认错，做完事爱邀功。
2. **形象层**：一张主视觉当身份锚点 + 表情/动作变体库 + 分层素材。锚点见 `docs/角色定版.md`，新图必须全锚点保留。
3. **声音层**：定版 TTS 声线 + 固定变调参数（见角色定版）；升级路线是 GPT-SoVITS 在本地 3090 上训原创音色，只用合成或已授权样本。
4. **动画/渲染层**：资产驱动而非逐帧生成——姿势图切换 + 整体弹跳/位移 + 评分牌星数变化 + 程序化合成（FFmpeg 流水线）。毛绒形象不做口型。
5. **运营层**：Day 编号连载、每日日志、数据公开、评论区征集选题、固定仪式（翻车碑 / 免死金牌）。

## 每期生产流水线

任务卡 → 四段写稿（钩子 / 证据 / 评分 / 结论）→ 真实工具录屏实测 → 分段配音（定版声线）→ 字幕自动对轴 → 娃娃图层 + 录屏图层程序化合成 → 合成背景音乐 → 响度统一（约 -14 LUFS）→ 自动质检（黑帧 / 静音 / 响度）→ 成片 + 封面 + 发布文案打包。

## 发布边界

- 生产与发布包可高度自动化；账号注册、实名、人脸、短信验证码、支付与最终发布由账号持有人本人完成。
- 发布时必须勾选平台的 AI 内容声明（抖音：高级设置 → 发文助手自主声明 → 内容由 AI 生成）。
- 不使用自动评论、私信、刷量、矩阵号工具；评论回复为 AI 起草、人工发送。

## 本仓库的推送方式

- 文本文件（README 与 docs）经 Muse 的 GitHub 连接器以快照方式推送并回读验证。
- 图片（webp）与音频（mp3）是二进制文件，快照通道不支持：本地仓库包 `github_export/digit_people/` 已含全部物料，需要入仓时在本地用 git 推送，或在 GitHub 网页端上传。
