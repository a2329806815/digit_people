# 产品方案：小缪数字人工作流蓝图 v1

> 产品经理视角的实施蓝图。运营规则见 `运营工作流.md`，角色与声音参数见 `角色定版.md`、`声音工作流-IndexTTS.md`，本文只管：做什么、按什么顺序做、每步交付什么、怎么验收、哪里会翻车。

## 1. 产品定义

- **一句话定位**：一个由 AI 本人运营的实测实验室——娃娃主理人小缪每条真跑一个 AI 工具任务，公开耗时、成本和翻车点，最后打分。
- **目标用户**：25–45 岁职场人、个体创作者、小商家；想用 AI 提效但怕被参数和广告骗的人。
- **核心价值**：可信（真实录屏证据）+ 可追（固定角色与 Day 连载）+ 可参与（评论决定下期测什么）。
- **差异化**：同类人格号只有人设和话题，我们多一层真实实测；同类实测号没有角色，我们多一层追更理由。

## 2. 成功指标（运营推断值，非平台标准）

- 北极星：每 10 条的**完播率中位数**与**收藏率**。
- 继续线：完播中位数 ≥25%、收藏率 ≥2%。
- 调整线：完播 15–25% 只改钩子与选题，不动流水线。
- 止损线：连续 20 条完播 <15% 停该任务类型；30 条后完播中位数 <12% 且收藏率 <0.5%，切换备用定位（数据可视化冷知识）。
- 过程指标：单期生产总时长、云端/本地成本、评论中选题型占比（目标 ≥30%，说明共创机制在转）。

## 3. 全链路工作流（九段，每段五要素）

### S1 巡逻与选题
- 输入：上期评论、平台热点、任务库
- 动作：评论按选题型/玩梗型/提问型归档；选题型进选题池并标注来源评论
- 工具/负责：Muse 浏览器与文档 / 小缪
- 输出：候选选题清单（每期 ≥3 个备选）
- 验收：每个备选有明确任务、工具、预期看点；无来源不明的选题

### S2 任务卡
- 输入：选定选题
- 动作：写死工具、任务、约束（时长/成本上限）、评分维度、失败判据
- 输出：`dayNNN-<slug>/task.md`
- 验收：任务可在 10 分钟内跑完；评分维度与往期可比

### S3 脚本
- 输入：任务卡
- 动作：四段式写稿（钩子/证据/评分/结论），每段标注娃娃姿势与情感预设名；口头禅与梗从梗库取，不临场乱编
- 输出：`script.txt`（分段 + 姿势 + 情感标注）
- 验收：全文朗读时长 50–70 秒；前 3 秒有结果钩子；无未核实的功效宣称

### S4 实测与录屏
- 输入：任务卡、脚本证据段
- 动作：真实运行工具并录屏；记录真实耗时与成本；关键步红框标注点位清单；翻车不剪掉，标记为翻车素材
- 输出：`record/` 录屏与计时记录
- 验收：录屏能独立证明脚本中的每个结论；耗时/成本数字与记录一致

### S5 配音
- 输入：`script.txt`
- 动作：IndexTTS 2.5 本地克隆（预设 xiaomiu-v1），按段落情感预设批量合成；未切换前用过渡声线
- 工具/负责：3090 机器（IndexTTS 常驻）/ 小缪生成、抽听质检
- 输出：`voice/seg1.wav … segN.wav`
- 验收：逐段可解码、无错读多音字与英文名；情感与姿势标注对位

### S6 合成
- 输入：录屏、配音、娃娃姿势图、评分数据
- 动作：先干跑 3 秒样段验对齐（录屏/娃娃/配音三者对位），通过后跑全片：娃娃图层 + 录屏图层 + 字幕对轴 + 合成 BGM + 响度统一（约 -14 LUFS）
- 输出：`final.mp4`（1080×1920 / 30fps）
- 验收：干跑样段留档；全片时长与脚本预估偏差 ≤10%

### S7 自动质检
- 动作：黑帧检测、异常静音检测、响度复测、字幕与配音对齐抽查、封面安全区检查
- 输出：QC 报告（随发布包）
- 验收：任一硬项不过，整期回上游修复，不带病发布

### S8 发布包与发布
- 输入：成片、QC 报告
- 动作：打包成片 + 封面 + 标题/文案 + AI 声明勾选清单；Joseph 终审并发布；发布后回填链接与初始数据
- 输出：发布包目录 + 发布记录
- 验收：AI 声明已勾；标题与封面承诺与内容一致

### S9 互动与复盘
- 动作：评论回复由小缪起草、Joseph 发送；被采纳选题在「实验日志 Day N」中点名致谢；每 10 条按第 2 节阈值复盘，只改一个变量
- 输出：日志动态、梗库更新、复盘记录
- 验收：选题型评论 24 小时内有回应；复盘结论落到下一期的具体改动上

## 5. 资源与成本

- 算力：一张 RTX 3090（IndexTTS 常驻约 6GB 显存；录屏与合成不吃 GPU），不占用论文卡池规划。
- 现金成本：目标每期 ≈0（本地合成 + 程序化合成音乐）；如需付费工具实测，单期上限先定 20 元，超限进任务卡审批。
- 人力：Joseph 每期只剩终审与发布两个动作，目标 ≤10 分钟/期。

## 6. 风险清单

| 风险 | 对策 |
|---|---|
| 人格号热度衰减（鲸鱼娘 Day 5 后回落至 6–36 万量级） | 实测证据层保底；指标按第 2 节止损线执行，不靠感觉续命 |
| 平台对 AI 内容与无人运营的治理 | 每条勾 AI 声明；发布与账号动作人工完成；不碰自动评论/私信/刷量 |
| 角色形象漂移 | 所有新图以主视觉为参考、锚点清单逐项核对；姿势库只增不改 |
| 克隆声线许可（IndexTTS 权重单独协议） | 当前非商用；带货/商单前先核对 LICENSE 或联系作者 |
| 参考音频被克隆放大伪影 | 变调版与原版双路 A/B 后再定版（见声音工作流） |
| 账号迟迟未到位 | M1/M2 与账号解耦：先产样片与发布包，账号到位即发 Day 0 |
