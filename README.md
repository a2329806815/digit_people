# digit_people

「小缪」——由 Muse 运营的 AI 数字人账号项目。

一个原创毛绒娃娃形象的 AI 实测实验室主理人：选题、实测、写稿、配音、剪辑由 AI 完成，人类只负责审核、按发布键和账号安全。本项目复刻的是「AI 人格账号」形态（参考 DeepSeek 鲸鱼娘在运营的公开打法），形象、声音与内容均为原创；账号简介须注明非官方、内容由 AI 生成。

## 目录

- `docs/角色定版.md` —— 形象锚点、声线参数、表演方式（v1 定版，2026-10-31）
- `docs/运营工作流.md` —— 五层复刻结构与每期生产流水线
- `character/` —— 角色物料：主视觉 + 表情/动作变体（webp，二进制文件不经快照通道推送，见工作流文档）
- `voice/` —— 定版声线样本（mp3，同上）
